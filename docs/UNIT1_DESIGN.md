# 第一单元 · Kennenlernen

面向约 14 岁中文母语学习者，使用德语 A1 短材料。地点是不同学习方式的入口：面包店读信息，公园回忆单词，学校组织表达。三个地点各有三个短练习，每个练习三个步骤，共 27 步。

## 面包店：阅读后回答店员

| 练习 | 材料 | 店员提问 |
| --- | --- | --- |
| 读懂柜台信息 | Mia 的选择、价格和清单 | 买什么、多少钱、需要几个 |
| 按清单回答 | 野餐清单与打包信息 | 还买什么、数量、打包还是堂食 |
| 核对订单与价格 | 食物、水和总价小票 | 食物种类、食物金额、含水总价 |

原文保持在场景上方，学生在侧面输入简短德语回答。反馈标出相关行，引导核对证据；数字价格与德语数词均有已编写的可接受表达。Mia 不代替店员提问，负责帮助学生回到原文。

## 公园：线索猜词

| 练习 | 词语 |
| --- | --- |
| 公园里有什么 | der Baum、die Blume、die Bank |
| 野餐物品猜词 | der Ball、das Wasser、der Rucksack |
| 天气与活动猜词 | die Sonne、spielen、blau |

每题先展示一条德语线索；答错或点“再给一条线索”增加中文语义提示，再增加字母提示。只输入单词或带正确冠词都可以；错误冠词需要修改。下一题恢复为一条线索。“查看例词”属于显式帮助，不算独立完成。

不因求助扣金币、不要求连续签到。学习重点是根据用途和情境回忆，而不是计时猜测。

## 学校：从短句到段落

| 练习 | 表达任务 |
| --- | --- |
| 写一句得体的回应 | 早晨问候、介绍名字、介绍年龄 |
| 把课堂需要写出来 | 有一支铅笔、礼貌借笔、说明书的位置 |
| 写一段自我介绍 | 星期一课表与喜好两句、课程与活动两句、4—5 句角色介绍 |

统一用虚构角色 Alex：14 岁，喜欢 Deutsch 和 Fußball spielen。学生不需要填写真实资料。段落提交后显示信息清单、句数、词数和一个优先修改建议，修改后重新提交。Mia 不直接重写整段。

本版规则检查只覆盖已编写的 A1 表达结构；它不是任意德语作文的完整语法评分器。LLM 可依据任务与规则结果补充讲解，不能自行发金币或绕过规则。无需 API Key 也可完成所有题目。

## 金币与进度

九个练习首次完成奖励依次为 40、50、60 / 50、50、70 / 50、50、60 金币，全部完成共 480 金币。重做不重复领奖；已有经验值余额按 1:1 作为金币保留。金币钱包与收支流水保存在当前账号下，为以后商店消费留出接口；本版不增加商店。

所有旧题直接替换。未完成的旧练习再次进入时从新版第一题开始；已完成标记、余额和历史提交不删除。旧页面提交会要求重新进入，避免把旧答案计入新题。

## 参考项目中的取舍

只读参考 D:/web/praktikum-llm 的 story_reading_service.py、story_vocabulary_service.py 和 story_writing_service.py：

- 阅读：把反馈关联到原文证据。
- 单词：逐步线索与重试，答错时不直接揭晓。
- 写作：按内容和语言组织局部反馈，让学生自己修改。

没有复制参考项目的意大利语故事或修改其文件。本项目保留现有小镇、Mia、双击式场景入口和账号数据库，以独立模块实现三种玩法。
