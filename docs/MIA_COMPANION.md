# Mia：一起观察、尝试和回忆的学习伙伴

面向约 14 岁、中文母语的学生，Mia 的核心作用是和学生完成真实的语言动作：看场景、想一句、试着说、检查线索、隔一会儿再想起来。她的表情和对话应与这些动作有关。

## 第一版已实现

| 时机 | Mia 做什么 | 学生仍负责什么 |
| --- | --- | --- |
| 地图首页 | 点击后中德混合欢迎；结合已完成进度建议下一站 | 自己选择地点 |
| 刚到场景 | 提一个观察问题，如在柜台找到 Brötchen | 先看插画、想一句，再主动开始练习 |
| 答题中 | 点击人物后可请求线索或提问；沿用当前步骤的教学 Agent | 自己组织答案，决定何时需要帮助 |
| 完成后 | 用本次独立完成步骤数描述具体进展，再给一个后续动作 | 选择继续、换地点或复习 |
| 单词卡 | 点击人物后提供回忆、联系场景与造句建议 | 先回忆再翻面，诚实自评 |

欢迎例子：Guten Tag! 欢迎来到第一单元 Kennenlernen。我是 Mia。我们先看看小镇，选好地点后再一起练德语。

点击角色只打开对话或帮助选择，不自动开始题目、提交答案或计算帮助。真正请求线索后，才使用原有帮助记录。角色不会自动弹出对话打断答题。

地图和场景的引导是本地编写内容。题目内的辅导可由既有 LLM 接口生成；评分、解锁和学习记录仍由后端规则决定。无需新增 API Key 或数据库字段即可使用本轮交互。

## 后续可增强的互动

1. 共同完成短对话：Mia 负责一个角色，学生完成另一个角色，每轮只有一个清楚的交流目标。
2. 请学生教 Mia：她提出一条需要检查的表达，学生找出问题并解释，帮助学生从辨认走向理解。
3. 跨场景回用：把面包店学到的数量和请求带到公园，Mia 提醒情境，学生独立选表达。
4. 更有依据的个别化：积累足够的独立作答与复习证据后，再调整提示深度和推荐任务。

以上后续互动尚未实现；第一版优先把地图、场景、题目和复习中的伙伴行为连接起来。
