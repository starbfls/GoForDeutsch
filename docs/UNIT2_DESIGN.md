# 第二单元 · Einkaufen

按约 14 岁、中文母语、德语 A1 学生设计。保留第一单元的阅读 → 猜词 → 写作结构，每个地点三个练习、每个练习三个步骤。共 9 个练习、27 个步骤；首次奖励合计 540 金币。

## 场景与内容

| 地点 | 玩法 | 三个练习 |
| --- | --- | --- |
| 服装店 · Modegeschäft | 阅读商品信息并回答店员 | 服装标签（粉色衬衫、M 码、24 欧元）；试衣信息（蓝夹克、S 码、试衣间在右侧）；购物小票（衬衫与裙子、26 欧元、合计 50 欧元） |
| 电器店 · Elektronik | 用途和特征猜词 | Handy / Kopfhörer / Laptop；Tastatur / Maus / Bildschirm；Kamera / Ladekabel / Lautsprecher |
| 餐厅 · Restaurant | 从一句请求到完整交流 | 菜单、披萨和水；两人桌、不加肉和结账；两句点餐、三句说明、四句完整用餐表达 |

每个地点的三个练习分别奖励 50、60、70 金币。阅读有原文与证据行；猜词初始一条线索，答错或求助追加；段落写作检查句数与必要信息，缺项时给修改清单。段落使用 Alex 与 Mia 的虚构设定，无需填写学生个人资料。

本地阅读支持已编写的短答、变音拼写及价格数字；启用 LLM 时沿用 Mia 的语义判断。猜词与写作沿用第一单元规则。模型不能操作金币或背包。

## 地图与主题

第一单元绿色，第二单元蓝色。商场玻璃穹顶、交错扶梯和三个店铺在全景与局部插画中保持一致。服装店粉色、电器店蓝色、餐厅暖木色，按钮使用对应图标与颜色。地图铺满视口、不拉伸、不画连接线。

第一次点地点，地图放大后进入场景预览；再点“开始练习”，才创建或恢复任务、显示题目。第二单元可选中查看地图，完成第一单元全部九个练习后才可开始服装店；后续依次解锁。旧进行中任务保持可恢复。

## 获得服装、背包与商店

- 默认校服始终拥有。背包中的预览都用 smile 默认表情。
- 完成服装店三个练习，自动获得参考图中的粉格便服，并开启商店。衣服放进背包，不自动替学生换装。
- 商店首版提供粉格奖励的状态和 240 金币的蓝格配色便服。金币不足无法购买；拥有后不再重复扣款。
- 从背包换装，地图、场景和单词卡的 Mia 都切换到这套服装的完整表情图集；可以随时换回默认校服。
- 每套图集均为 4 列 × 3 行，11 个表情加闭眼帧。smile 默认表情保留不固定间隔的眨眼。
- 服装仅改变外观，不影响题目、提示、通关与金币奖励。

服装奖励与完成结果在同一个事务写入；购买时库存、钱包和流水同时提交或同时回滚。登录账号按稳定账号 UUID 保存服装归属与当前穿着；访客另存。重复请求不会重复发服装或扣金币。

## 单词卡

保持初始为空。电器店每次猜对后可主动收录该词；通关后可勾选关联词，不预选、不自动添加。既有词如 blau、Wasser、bitte 跨场景共用词卡。第二单元新增 21 个目录词条，只有学生主动收录的词才进入个人卡库。
