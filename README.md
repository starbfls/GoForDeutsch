# GoForDeutsch · 和 Mia 一起学德语

面向中文母语学生、按 **14 岁**的阅读和审美设计的德语 A1 游戏化学习原型。第一单元 **Kennenlernen** 是小镇里的面包店、公园和学校，第二单元 **Einkaufen** 是商场里的服装店、电器店和餐厅。两个单元都以阅读、猜词和写作组织学习，Mia 负责给线索与修改建议。

当前项目目录：`D:\web\GoForDeutsch`。

## 最简单的打开方式（Windows）

1. 打开 `D:\web\GoForDeutsch`。
2. 双击 **`Start-GoForDeutsch.cmd`**。
3. 等待准备完成，浏览器会自动打开 **http://127.0.0.1:8000**。
4. 保持启动窗口打开。结束体验时，在窗口按 **Ctrl+C**。

第一次启动需要电脑已安装 **Python 3.10+** 和 **Node.js 22.12+（或受支持的更新 LTS 版本）**。如果缺少项目依赖，启动器会联网安装；后续通常不需要重新安装。打开失败时，启动窗口会保留错误信息。

也可以在 PowerShell 中运行：

```powershell
cd D:\web\GoForDeutsch
python launcher.py
```

无需 API Key 即可体验两个单元、18 个完整练习并选择收录单词卡。此时 Mia 使用经过编写的固定教学提示，不消耗模型额度；设置里可查看辅导模式。

- 单词卡初始为空；猜对单词或通关后主动选择加入，按账号去重。悬停可查看中文、例句与记忆联想。
- 保留翻面复习、收藏、场景筛选和每组最多五张的自评复习。

- 场景内可切换三个练习；跨地点时返回大地图选择下一站。手机上练习排列在场景下方。
- 场景切换和表情切换动效；支持界面和系统的减少动态设置，页面切到后台会暂停眨眼。
- 阅读原文与证据定位、逐条线索猜词、课堂短句与自我介绍写作；提示、例句和围绕当前步骤向 Mia 提问。
- 原有注册、登录、退出、访客体验、进度恢复和首次完成金币奖励。

第二单元 **Einkaufen** 已开放：蓝色主题的现代商场，服装店阅读 → 电器店猜词 → 餐厅写作，新增九个练习、27 个步骤。可从右上角单元选择器查看商场，完成第一单元九个练习后开始服装店。第一单元已有账号、进度、提交历史、词卡和余额保留，正在进行的新版练习不会因新增第二单元被重置。

第一版不包含听力、麦克风、角色语音包、课件上传或多人游戏。

## 接入 DeepSeek：Mia 判题与辅导

本机配置已准备在 `D:\web\GoForDeutsch\backend\.env`。打开文件，在 `DEEPSEEK_API_KEY=` 的等号后填写你自己的 API Key，并把 `AI_ENABLED` 改为 `true`：

```dotenv
AI_ENABLED=true
AI_PROVIDER=deepseek
DEEPSEEK_API_KEY=在本机填写你的DeepSeek_API_Key
DEEPSEEK_MODEL=deepseek-flash
DEEPSEEK_BASE_URL=https://api.deepseek.com
AI_DAILY_LIMIT=30
```

当前选用 **DeepSeek V4.1 Flash**。截至 2026-11-17，官方 API 模型 ID 是 `deepseek-flash`，对应 V4.1-Flash-1017；配置填写这个 ID，不填展示名称。旧的 `deepseek-v4-flash` 已由官方兼容路由到新版，无需切回旧 ID。依据：[官方模型列表](https://api-docs.deepseek.com/api/list-models/)、[官方更新记录](https://api-docs.deepseek.com/updates/)。

保持原有 `SECRET_KEY` 不变，不要把密钥写到前端、发到聊天或提交 Git。填写后关闭旧启动窗口，再运行 `python launcher.py`。设置中会显示当前提供商与模型。

接入依据：[DeepSeek 官方 API 说明](https://api-docs.deepseek.com/)、[JSON 输出说明](https://api-docs.deepseek.com/guides/json_mode/)。模型可按账号实际权限修改。本项目使用标准库 HTTP 请求，无需新增 SDK。

阅读与写作先确认已审定的正确表达，直接通过且不请求模型；其余表达启用模型后，由 Mia 结合题目、材料和内容标准判断语义，同一次调用返回正误与评估。参考答案不是唯一写法；`ein Broetchen`、`Ein Brötchen`、`Ich möchte ein Brötchen` 均可表达买一个小面包。`bitte` 是礼貌建议，不作为通关门槛。数量、物品、价格和否定仍要区分。

猜词继续由本地规则检查目标词；短句与段落写作不再只允许预设整句，未覆盖的写法由模型按任务内容和核心语言结构判断。DeepSeek 也可为提示、例句和提问提供讲解。模型不能直接发金币、操作账号或把单词自动加入卡库。

未配置、额度上限、网络失败、空/截断/不符合格式的响应会回退到本地确认；已审定表达仍可通过，无法确认的自由表达显示“暂未确认，答案已保留”，不冒充答错、不自动通关，也不扣除独立完成资格。本地模式无法穷尽所有自由表达。`AI_DAILY_LIMIT` 是全站每天按 UTC 计算的调用尝试上限，包含判题、辅导和失败请求，不是账单金额限制。

本次除模拟协议和异常测试外，使用现有 DeepSeek 配置做了3次真实判题验证，两条合法新表达通过、一条核心语法错误被拒绝；未修改每日上限。收录单词卡本身不请求模型。判题标准和代码位置见 [docs/ASSESSMENT.md](docs/ASSESSMENT.md)。

原有 OpenAI 配置仍可使用：设置 `AI_PROVIDER=openai`，保留 `OPENAI_API_KEY`、`OPENAI_MODEL` 即可走已有 Responses 接口。两个提供商分别读取各自密钥；只有 OpenAI 请求带 `store=false`，DeepSeek Chat Completions 不发送该字段。

## 单词卡怎么用

**初始卡库为空，完成学习不会自动塞入全部词汇。**

- 公园与电器店猜词：每次答对后，可点击该词旁的“加入单词卡”，也可以直接继续。
- 练习通关：勾选想复习的词，再点“加入所选”；默认不勾选，可以跳过。
- 同一账号重复加入同一个词不会重复建卡；背包等跨场景复用的单词共用一张卡。
- 登录账号与游客分别保存收录、收藏和复习状态。刷新、重新登录与重启后仍保留。
- 旧版复习和收藏记录不会被删除；重新主动收录该词后继续使用。旧的全词汇列表不会自动转成个人收藏。

进入“单词卡”后可筛选场景、待复习、全部和收藏。鼠标悬停展开中文、例句与记忆联想（Eselbrücke）；键盘聚焦或手机点击也能展开。释义与联想采用已编写的德语材料。

点击“复习 5 张”或单卡复习，先回忆，再翻面自评：

- 再学一次：约 10 分钟后到期。
- 模糊：至少 1 天后。
- 记得：至少 3 天后。
- 熟悉：至少 7 天后。

后续间隔根据上次间隔增加；这是简单的自评安排，不代表长期掌握度评估。收藏是个人卡库内的标记，与“加入单词卡”分开。参考项目中的主动保存、按用户去重和悬停记忆联想用于本版设计，未采用其答错后自动收录的行为。

## Mia 怎么陪你学

地图上点击 Mia，可以听她介绍单元、建议下一站或聊聊怎么学。她会根据已有进度推荐地点；你仍可自己选择。

点击地点先进入场景，可以观察插画、和 Mia 聊一句，再点“开始练习”。在题目中点击 Mia，可选择“给一点线索”或“我想问问”；主动请求线索沿用原有帮助记录。完成后，她会结合本次独立完成的步骤数给出下一步建议。单词卡旁点击 Mia，可查看先回忆、再翻面和用词造句的建议。

地图欢迎、场景观察和单词卡学习建议是预先编写的内容，不会因点击而请求付费模型。答题时的提示、例句和提问继续使用既有教学 Agent；是否调用 LLM 取决于本机配置。设计说明见 [docs/MIA_COMPANION.md](docs/MIA_COMPANION.md)。

## AI 与教学 Agent 的职责

课程词汇、教学目标、任务顺序和基础答案由项目明确编写。规则检查器处理本版支持的答案，服务器决定解锁、金币和进度。阅读与写作未被本地正确表达覆盖时，由 Mia 返回结构化语义判断；模型不能直接操作数据库、金币或单词卡。

教学 Agent 读取当前任务、尝试次数和提示记录，再通过结构化输出返回：一段短辅导、一个允许的表情、一个教学动作（观察、提示、示例、重试或迁移）。它没有浏览网页、执行任意代码或修改数据库的权限。

第一版的“独立完成”指：该步骤第一次回答正确，且没有使用提示、示例或提问。答错后的纠正也属于帮助。每个练习首次完成只奖励一次金币，学习记录保留最近一次完整练习的表现；目前不代表长期掌握度评估。

未连接 AI 时，阅读、短句和段落使用经过审定的答案与句式族，未覆盖的写法保持未确认。连接后，未覆盖的阅读和写作使用结构化语义评估；段落逐项检查角色信息、句数、词数与基本语言结构，服务器验证内容证据和评估一致性。模型只提交判断与辅导，服务器负责保存和发放首次奖励。

## 数据保存在哪里

- 账号：`backend/data/users.json`，密码保存为 bcrypt 哈希。
- 按账号保存的单元/场景/练习/步骤位置、完成状态、每次提交的答案与提问、正误和时间，以及 金币钱包/流水：`backend/data/learning.sqlite3`。
- 每日 AI 调用计数、单词卡收录/收藏/复习状态、服装库存及当前穿着继续保存在同一个 SQLite 文件中。无需另开数据库或云服务。
- 金币区分可用余额、累计获得、累计消费。原有经验值按 1:1 保留为金币，不重复入账；首次完成奖励只发一次，未来消费后不会因刷新而恢复。商店在完成服装店后开放，商品价格由后端确定。
- 首次升级自动备份旧 SQLite 到 `backend/data/backups/`，保留历史结果并将旧关卡奖励一次性记入钱包。旧版没有记录的答案无法补回；未提交草稿不保存。
- 更新后关闭原启动窗口，再运行 `python launcher.py` 即可自动升级。数据表和本人查询接口见 [docs/DATABASE.md](docs/DATABASE.md)。
- 浏览器保存随机访客标识；不需要姓名、邮箱或生日即可体验。
- 访客与登录账号的进度分开保存，暂不自动合并。清理浏览器存储后，旧访客记录不会自动找回。
- 后端数据目录及本机配置不进入 Git。不要手动覆盖原有用户数据。

## 常见问题

**8000 端口已被占用**：关闭上一次启动窗口后再打开。启动器不会自动结束其他程序。

**提示未连接学习服务**：确认启动窗口仍在运行；开发模式下确认后端已启动。若旧登录过期，可重新登录或选择访客体验。

**首次安装失败**：确认 Python、Node.js 可在终端运行，且能访问对应依赖源。把启动窗口里的错误信息用于排查。

**注册日志出现 bcrypt 的 `__about__` 报错**：旧版 Passlib 与 bcrypt 的版本信息不兼容。当前代码已改为直接使用 bcrypt，保留旧账号密码格式；更新代码后重启即可，不需要重新注册。日志中的 `201 Created` 表示注册请求已经成功。

**登录状态重启后失效**：保持 `.env` 中 `SECRET_KEY` 不变。未设置固定值时，后端会使用进程级随机值。

**字体加载慢**：界面可使用系统中文字体；远程字体不可用时不影响学习功能。

**想减少动画**：打开“设置”，关闭“场景与角色动态”。

**修改后仍是旧界面**：关闭原启动窗口，重新双击 `Start-GoForDeutsch.cmd`，然后刷新浏览器（必要时 Ctrl+F5）。
